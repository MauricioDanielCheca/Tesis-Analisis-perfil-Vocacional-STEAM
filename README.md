
# Análisis del Perfil Vocacional para Carreras STEAM en Estudiantes de Bachillerato


El ciclo de vida de los datos del proyecto se estructura siguiendo la **Metodología OSEMN**:
* **Obtain (Obtener):** Recolección y consolidación de instrumentos de evaluación físicos y digitales.
* **Scrub (Limpiar):** Tratamiento de valores atípicos, codificación de variables categóricas y limpieza de ruido.
* **Explore (Explorar):** Análisis estadístico para identificar patrones, distribuciones y correlaciones iniciales.
* **Model (Modelar):** Implementación de regresión logística, análisis de pruebas estadísticas no paramétricas.
* **iNterpret (Interpretar):** Diseño de tableros de control interactivos para presentar métricas clave a los tomadores de decisiones.

## Tecnologías y Herramientas Utilizadas
* **Lenguaje principal:** Python
* **Procesamiento y Modelado:** Pandas, NumPy, SciPy, Scikit-Learn, Statsmodels
* **Visualización en Python:** Matplotlib, Seaborn, Plotly
* **Inteligencia de Negocios:** Power BI (Dashboards de resultados)
